## Phase 3 — 3D Hero (Three.js) — headline feature
1. `npm i three @react-three/fiber @react-three/drei`
2. Naya `src/components/HeroScene.tsx`:
   - Light-theme friendly scene: floating icosahedron/torus-knot cluster indigo (#4F46E5) + zinc tones, `Float` (drei) se gentle bobbing
   - Mouse parallax (group rotation lerp toward pointer)
   - Hero ke background mein absolute-positioned canvas — text contrast safe (low opacity, edges ki taraf)
3. Performance/a11y guardrails:
   - `React.lazy` + `Suspense` — 3D chunk hero ke baad load hoga
   - Rendering pause jab hero viewport se bahar scroll ho (IntersectionObserver) ya tab hidden ho
   - `prefers-reduced-motion` → static/skip render; WebGL fail ho to silent fallback
   - `dpr={[1, 1.75]}` cap
4. **Commit + push**: `feat: add interactive Three.js 3D hero scene`
